gswitch-auto

Исправляет слова, набранные не в той раскладке, — сам, как Punto Switcher. Для Linux с GNOME: Fedora 44 на Wayland и Debian 12 на Xorg.

Fixes words typed in the wrong keyboard layout — automatically, like Punto Switcher. For Linux with GNOME: Fedora 44 on Wayland and Debian 12 on Xorg.

Форк gswitch: всё ручное исправление на месте, плюс автоматический режим для пары раскладок us + ru. Работает локально — без сети и без нейросетей.

A fork of gswitch: all of its manual correction, plus an automatic mode for the us + ru layout pair. It runs locally — no network, no LLM.

ВозможностиFeatures

Что добавляет форкWhat the fork adds

gswitch исправляет текст только по нажатию триггера. gswitch-auto умеет делать это сам — и остаётся предсказуемым: исправляет лишь явные случаи, ничего не делает по Enter и отменяется одним жестом.

gswitch fixes text only when you press a trigger. gswitch-auto can do it by itself and stays predictable: it fixes only clear cases, never acts on Enter and is undone with one gesture.

Автоматический режимAutomatic mode

После пробела слово проверяется: ghbdtn → привет, руддщ → hello. Слово стирается, раскладка переключается, текст перепечатывается. Enter исправление не запускает, а любая клавиша во время паузы его отменяет.

After Space the word is checked: ghbdtn → привет, руддщ → hello. The word is erased, the layout switched and the text retyped. Enter never triggers a fix, and any key pressed during the pause cancels it.

По умолчанию выключен.

Off by default.

Отмена одним жестомOne-gesture undo

Двойной Shift сразу после автоисправления возвращает исходное слово и раскладку. Отменённое слово можно запоминать как исключение — второй раз оно не исправится.

Double Shift right after an automatic fix restores the original word and layout. The undone word can be learned as an exception, so it is not fixed again.

Режим одним аккордомOne chord to toggle

LShift+RShift вместе включают и выключают автоматический режим. Состояние видно в меню трея и сохраняется.

LShift+RShift together turn automatic mode on and off. The tray menu shows the state, and it is saved.

Выделенный текстSelected text

LShift+RAlt+RCtrl переводит выделенный фрагмент в другую раскладку. Привычный Ctrl + двойной Shift из gswitch тоже работает.

LShift+RAlt+RCtrl converts the selected text to the other layout. gswitch's Ctrl + double Shift still works too.

ИсключенияExceptions

Слова, которые никогда не исправляются, и программы, где автоматический режим выключен. Терминалы, поля паролей и экран блокировки пропускаются по умолчанию.

Words that are never corrected and applications where automatic mode is off. Terminals, password fields and the lock screen are skipped by default.

Настройки в трееSettings in the tray

Вкладка «Автоисправление»: режим, слова и программы-исключения, сочетания клавиш, управление службой — запуск, остановка, перезапуск, автозапуск. Новые строки интерфейса — на русском и английском.

An "Auto correction" tab: the mode, exception words and applications, hotkeys and service control — start, stop, restart, start at login. The new interface strings exist in English and Russian.

Локально и быстроLocal and fast

Детектор языка — Go-порт модели punto-rs: фильтр Блума и буквенные триграммы. Проверка слова занимает микросекунды, без сети и без LLM.

The language detector is a Go port of the punto-rs model: a Bloom filter and letter trigrams. A word is checked in microseconds, with no network and no LLM.

Всё из gswitch — на местеAll of gswitch is kept

Двойной Shift для последнего слова, фраза с зажатым Shift, выделение, смена регистра, отмена повтором триггера — работают как раньше. Пакет заменяет gswitch на месте: те же команды и пути.

Double Shift for the last word, the held-Shift phrase gesture, selection, case swap and undo by repeating the trigger work as before. The package replaces gswitch in place: same commands and paths.

Понимает окно и полеKnows the window and field

Небольшое расширение GNOME Shell сообщает, какая программа в фокусе и что за поле ввода (текст, пароль, терминал). Заголовков окон и текста оно не передаёт.

A small GNOME Shell extension reports which application has focus and what kind of field it is (text, password, terminal). It exposes no window titles and no text.

Chords are pressed together and released. You can change them in the tray settings.

ПлатформыPlatforms

Две системы — одни и те же бинарникиTwo systems, the same binaries

Демон сам выбирает источники при запуске — по типу сеанса и версии GNOME Shell. Пара раскладок — us + ru, архитектура — x86_64.

The daemon picks its sources at start from the session type and the GNOME Shell version. The layout pair is us + ru, the architecture x86_64.

В других окружениях — GNOME на Wayland ниже 49.3, KDE, другие пары раскладок, без IBus — автоматический режим сообщает, что недоступен, а всё остальное работает как в gswitch. На X11 поля паролей Qt-программ и XIM-клиентов (xterm, Emacs, Java, Wine) выглядят как обычный текст: их защищает только список программ-исключений, и основные в нём уже есть. Elsewhere — GNOME Wayland below 49.3, KDE, other layout pairs, no IBus — automatic mode reports itself as unavailable and everything else works like gswitch. On X11, password fields of Qt applications and XIM clients (xterm, Emacs, Java, Wine) look like ordinary text: only the exclusion list protects them, and it already contains the common ones.

УстановкаInstall

Сборка и установкаBuild and install

До первого релиза пакеты собираются из исходников. Сборки вида 0.8.0+auto.0.dev<n>.g<commit> уже заменяют gswitch 0.8.0, а откат — обычная установка пакета gswitch обратно.

Until the first release, packages are built from source. Builds versioned 0.8.0+auto.0.dev<n>.g<commit> already replace gswitch 0.8.0, and rolling back is just installing the gswitch package again.

  1. Инструменты сборкиBuild tools

    Go, компилятор C (CGO), заголовки GTK3 и X11, а также nFPM для упаковки.

    Go, a C compiler (CGO), GTK 3 and X11 headers, and nFPM for packaging.

    sudo dnf install golang gcc make pkgconf-pkg-config gtk3-devel libxkbcommon-devel libX11-devel rpm cpio python3 nodejs
go install github.com/goreleaser/nfpm/v2/cmd/nfpm@v2.48.0   # installs ~/go/bin/nfpm

  2. Сборка RPMBuild the RPM

    Нужен полный клон с тегами (не --depth 1): версия пакета вычисляется от тега v0.8.0. make rpm прогоняет тесты и проверки пакета.

    Use a full clone with tags (not --depth 1): the package version is derived from the v0.8.0 tag. make rpm runs the tests and the package checks.

    git clone https://github.com/vabuter/gswitch-auto.git
cd gswitch-auto
make rpm                                      # dist/gswitch-auto-<version>-1.x86_64.rpm

  3. УстановкаInstall

    Пакет заменяет gswitch (Obsoletes: gswitch < 0.9) с теми же командами и путями.

    The package replaces gswitch (Obsoletes: gswitch < 0.9) with the same commands and paths.

    sudo dnf install ./dist/gswitch-auto-*.rpm
systemctl --user enable --now gswitch.service # only if it is not running yet

  4. Перезайти и включитьLog in again and enable

    Выйдите из сеанса и войдите снова: GNOME Shell загрузит расширение, запустится новый трей. Включите расширение в трее («Автоисправление» → «Исключённые приложения» → «Включить») или командой ниже, затем включите автоматический режим: LShift+RShift.

    Log out and back in: GNOME Shell loads the extension and the new tray starts. Enable the extension in the tray ("Auto correction" → "Excluded applications" → "Enable") or with the command below, then turn automatic mode on: LShift+RShift.

    gnome-extensions enable gswitch-focus@vabuter.github.io
Нужен сеанс «GNOME на Xorg» (выбирается шестерёнкой на экране входа). Под Wayland у GNOME 43 нет источника раскладки, и автоматический режим будет недоступен. Use the "GNOME on Xorg" session (the gear icon on the login screen). Under Wayland, GNOME 43 offers no layout source, and automatic mode stays unavailable.

Как это работаетHow it works

От нажатия клавиши до исправленияFrom keystroke to fix

Как и gswitch, демон работает на уровне ввода Linux, поэтому исправление действует во всех программах — без плагинов для браузера или редактора.

Like gswitch, the daemon works at the Linux input layer, so corrections work in every application — no browser or editor plugins.

  1. НажатияKeystrokes

    Демон читает нажатия из /dev/input (evdev) и копит сканкоды текущего слова.

    The daemon reads keystrokes from /dev/input (evdev) and buffers the scancodes of the current word.

  2. Два прочтенияTwo readings

    Таблица «сканкод → клавиша XKB» даёт слово сразу в обеих раскладках.

    A scancode → XKB key table renders the word in both layouts at once.

    ghbdtn ⇄ привет

  3. ДетекторDetector

    Фильтр Блума и буквенные триграммы решают, какое прочтение — настоящее слово и с каким запасом.

    A Bloom filter and letter trigrams decide which reading is a real word, and by what margin.

  4. КонтекстContext

    Какая раскладка активна (IBus или группа XKB), какая программа в фокусе и что за поле, нет ли слова или программы в исключениях.

    Which layout is active (IBus or the XKB group), which application has focus and what kind of field it is, and whether the word or app is an exception.

  5. ПаузаHold-off

    120 мс тишины после пробела. Любая клавиша в это время отменяет исправление; Enter его не запускает.

    120 ms of quiet after Space. Any key in that window cancels the fix; Enter never starts one.

  6. ИсправлениеFix

    Через виртуальную клавиатуру uinput: Backspace, переключение раскладки с подтверждением, перепечатка слова.

    Through a uinput virtual keyboard: Backspace, a confirmed layout switch, the word retyped.

ПриватностьPrivacy

Клавиатура — дело личноеYour keyboard is your business

Программа видит всё, что вы набираете, поэтому правила простые и проверяемые в исходниках.

The program sees everything you type, so the rules are simple and checkable in the source.

  • Нет сетевого кода. Только локальные сокеты: сессионная шина D-Bus, шина IBus и, на X11, X-сервер. No network code. Local sockets only: the session D-Bus, the IBus bus and, on X11, the X server.
  • Текст не сохраняется. На диск попадают только слова-исключения — ваши и выученные при отмене. Text is not stored. Only exception words reach the disk — yours and those learned on undo.
  • Песочница gswitch сохранена. systemd-юнит не изменён (ProtectHome=read-only): демон ничего не пишет в домашний каталог. gswitch's sandbox is kept. The systemd unit is unchanged (ProtectHome=read-only): the daemon writes nothing to your home.
  • Расширение знает минимум. Только id программы, WM_CLASS и тип поля — без заголовков окон, текста и PID. На экране блокировки GNOME его отключает. The extension knows the minimum. Only the app id, WM_CLASS and field type — no window titles, text or PIDs. GNOME disables it on the lock screen.
  • Слова на шине — по желанию. Исправленные слова видны в D-Bus, только пока ipc-expose-words=true; в журнал они не пишутся. Words on the bus are optional. Corrected words appear on D-Bus only while ipc-expose-words=true; they are never logged.
  • И эта страница ничего не загружает со сторонних серверов: ни шрифтов, ни счётчиков. This page too loads nothing from third-party servers: no fonts, no trackers.
